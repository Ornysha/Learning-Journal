## Content Insights

This week I learned that PHP runs on the server and generates dynamic content before sending it to the browser.

I learned how to use:
- `echo` to display HTML content using PHP
- `if/else` statements to make decisions
- loops like `for`, `while`, and `foreach`
- arrays to store multiple values
- functions with parameters to reuse code
- `include` to reuse header and footer across pages

One important concept I understood is how PHP helps avoid repeating code. For example, instead of writing the same header and footer on every page, I used `include`, which made the code cleaner and easier to manage.

### Problem I faced

At first, my PHP file was not running properly. It was showing as plain text in the browser instead of executing.

After checking, I realised I opened the file directly instead of using:

http://localhost/prac7/index.php

I also found that one of my files was saved incorrectly as `.php.txt`.

### How I solved it

I enabled file extensions in Windows, corrected the file name to `.php`, and opened it through localhost using XAMPP. After that, the code worked properly.

I also used ChatGPT to confirm the correct way to run PHP locally.
