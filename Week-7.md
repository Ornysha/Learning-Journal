# Week 7 - PHP

## Learning Activities & Resources

This week I focused on learning the basics of PHP and how it works with web pages. I explored how PHP can be used to generate dynamic content instead of just static HTML.

Resources used:
- YouTube tutorials on PHP basics
- Online examples to understand loops and functions in PHP

---

## Estimated Hours

3 hours

---

## Content Insights

This week I learned that PHP is used to create dynamic web pages by running code on the server.

I learned how to use:
- echo to display HTML content using PHP
- if/else statements to make decisions
- loops like for, while, and foreach to repeat actions
- arrays to store multiple values
- functions with parameters to reuse code
- include to reuse common parts like header and footer

One important thing I understood is how PHP makes websites more efficient by avoiding repeated code. For example, using include for header and footer makes the site easier to manage.

---

## Career / Employability / Learning Insights

This week helped me understand how backend development works at a basic level. Before this, I mainly worked with frontend tools like HTML and CSS, but PHP showed me how logic and programming are used to control websites.

I also realised that writing small programs and testing them step by step helped me understand better than just reading theory. When something didn’t work, I had to check my code and fix errors, which improved my problem-solving skills.

Another important insight is that reusable code, like functions and includes, is very important in real projects. It saves time and makes the code cleaner and easier to maintain.

Overall, this week improved my confidence in working with programming logic and helped me understand how dynamic websites are built.
