# Week 8 – Learning Experiment

## Learning Activities & Resources

This week I focused on testing different learning methods to improve how I understand CMS concepts.

- Watched YouTube tutorials on WordPress and Joomla customization  
- Followed tutorials while practising directly on my local website  
- Compared passive watching vs hands-on learning approach  
- Used ChatGPT to clarify small doubts and errors  

Resources used:
- https://www.youtube.com/  
- https://wordpress.org/documentation/  
- ChatGPT  


---

## Estimated Hours

Approximately 3–4 hours  

---

## Content Insights

Through this experiment, I learned that there is a big difference between just watching tutorials and actually practising.

When I only watched videos, I understood the idea but could not remember the steps properly later. However, when I practised along with the tutorial, I was able to repeat the same task without help.

This helped me understand that CMS learning is more practical and requires active involvement. It also showed me that making small mistakes during practice improves understanding. This connects with the subject approach where we are expected to test and explore different methods instead of only following instructions.

---

## Career/Employability/Learning Insights

This experiment helped me understand how I learn best. I realised that passive learning like watching videos is not very effective for me, especially in technical subjects.

Instead, using a “learn by doing” approach keeps me more engaged and helps me remember concepts for a longer time. This is important for employability because in the IT industry, developers are expected to solve problems by experimenting and practising, not just by following tutorials.

I also learned that using tools like ChatGPT can support learning, but it should only be used to assist understanding, not replace practice. In the future, I will focus more on hands-on learning and testing things myself to improve my skills.
