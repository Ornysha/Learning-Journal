## Content Insights

The most important thing I learned this week is that in WordPress, pages and templates are different.

At first, I was editing only the template and did not create real pages. Because of this, my links were opening the admin editor instead of a proper page URL.

I learned that:

- Pages create real website URLs.
- Templates control layout and design.
- The header and navigation are part of the template, not inside individual pages.
- A static homepage must be set manually in Settings → Reading.

Understanding this structure helped me fix my linking problems and organise the site properly.
