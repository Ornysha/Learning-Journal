# Week 6 - Group Setup

## Learning Activities & Resources

This week I focused on learning how teamwork tools are used in real-world projects. Instead of just completing the practical, I explored how tools like Slack, GitHub, and Trello are actually used in industry environments.

I also looked at how GitHub repositories work in teams, including commits, collaboration, and version control. I learned how Slack integrates with GitHub and project boards to improve communication.


---

## Estimated Hours

Approximately 4 hours

---

## Content Insights

This week helped me understand how different tools work together in a team environment. Before this, I thought GitHub was mainly used to store code, but I learned that it is also very important for collaboration and tracking changes through commits.

I also understood how Slack is not just for messaging, but can be integrated with GitHub and project boards to receive updates automatically. This makes communication faster and more organised.

Another important thing I learned is how project planning tools like Trello or GitHub Projects help in dividing tasks among team members. Instead of everyone doing random work, tasks are clearly assigned, tracked, and updated.

The group agreement was also an important part. It made me realise that teamwork is not only about technical skills, but also about communication, responsibility, and expectations. Setting clear rules at the beginning can help avoid problems later.

---

## Career/Employability/Learning Insights

This week made me realise that technical skills alone are not enough in real jobs. Being able to work in a team and use tools like GitHub, Slack, and Trello is equally important.

I also noticed that clear communication is very important. If team members do not communicate properly, even simple tasks can become confusing. Using Slack regularly and keeping updates visible helps improve teamwork.

One learning strategy that worked for me this week was learning by doing. Instead of only watching tutorials, actually using GitHub and Trello helped me understand things much better. I found that trying things myself and then searching for help when needed was more effective than only reading or watching.

Overall, this week improved my understanding of teamwork in software development and made me feel more confident about working in group projects in the future.
