# Week 6 - Group Setup

## Learning Activities & Resources

This week I focused on learning how teamwork tools are used in real-world development projects. I explored tools like Slack, GitHub, and Trello and how they are connected in a team environment.

Resources used:
- https://docs.github.com/en/get-started/quickstart
- https://trello.com/guide
- Slack help documentation
- ChatGPT for understanding setup and integration

Some prompts I used:
- "How do I make my first commit in GitHub?"
- "How to connect GitHub with Slack using commands?"
- "What should I write in a group agreement for a project?"

These helped me understand the setup process and what is expected in a real team workflow.

---

## Estimated Hours

Approximately 4–5 hours

## Content Insights

This week helped me understand how different tools work together in a team project. Before this, I thought GitHub was mainly used to store code, but I learned that it is also used to track changes and contributions from each team member.

I learned how to make my first commit in GitHub by editing the README file and adding my contribution. At first, I was confused about what to commit and where to start, but after some research and using ChatGPT, I understood that even a small contribution like updating a file is enough to show participation.

### Problem I faced

Initially, I was unsure how to properly contribute to the GitHub repository. I didn’t know whether I needed to upload a full project or just a small change.

### How I solved it

I searched for examples and asked ChatGPT for guidance. I learned that making a simple commit like editing the README or adding a small file is acceptable. After doing this, I understood how commits work and how changes are tracked.

I also learned how Slack can be integrated with GitHub so that updates appear automatically in the chat. This showed me how communication and development tools are connected.

Another important learning was using Trello for project planning. I saw how tasks can be assigned, tracked, and updated instead of working randomly. This made the workflow more organised.

The group agreement was also useful. It helped me understand that teamwork is not only about technical skills, but also about responsibility, communication, and expectations.

---

## Career/Employability/Learning Insights

This week made me realise that teamwork skills are very important in real jobs. Knowing how to use tools like GitHub, Slack, and Trello is just as important as technical coding skills.

I also learned that communication is a key part of teamwork. If team members do not communicate properly, tasks can become confusing or duplicated. Using Slack regularly helps keep everyone updated.

One learning strategy that worked well for me was learning by doing. Instead of only watching tutorials, I tried using GitHub and Trello myself, which helped me understand better.

I also realised that asking for help (through ChatGPT or documentation) is an important part of learning. However, I made sure to understand the answers instead of just copying them.

Overall, this week improved my understanding of how real software teams work and made me more confident in contributing to group projects.
